## 🚀 Projeto em destaque

### [MKT-GUS](https://github.com/LucasGuedesLacerda/MKT-GUS)

Sistema de autoatendimento / totem de ponto de venda desenvolvido com arquitetura limpa (**Clean Architecture**) no back-end.

| Camada / Componente | Tecnologia |
|---|---|
| Back-end | Java 21 + Spring Boot |
| Arquitetura | Clean Architecture (Domain → Use-Cases → Adapters) |
| Banco de grafos | Neo4j (catálogo de produtos e relacionamentos) |
| Banco de séries temporais | TimescaleDB (métricas e logs de pedidos) |
| Edge / CDN | Cloudflare (Workers, R2, Cache) |
| Infraestrutura | Docker + Docker Compose |
